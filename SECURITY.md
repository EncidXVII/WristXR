# Security policy

WristXR injects mouse and keyboard input into your desktop and listens on localhost (notification API on
UDP 42069, VRChat OSC), so security reports are taken seriously.

**Report a vulnerability privately** via
[GitHub private vulnerability reporting](https://github.com/EncidXVII/WristXR/security/advisories/new).
Please don't open a public issue. You'll get an answer within 7 days.

Supported versions: the latest release only. Releases ship with SHA-256 checksums; verify downloads against
them. See also the [code signing policy](docs/code-signing-policy.md).
